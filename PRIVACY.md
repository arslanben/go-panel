# Privacy

Go Panel does not collect, transmit, or sell personal data.

- The API key you enter is stored locally on your device in encrypted storage.
- The only network request is `GET https://opencode.ai/console/api/go/status` with your API key in the `Authorization` header.
- Usage values are stored locally so the widget can render without a network request.
- There are no analytics, ads, crash reporters, or third-party SDKs.
- The app does not request your name, email, location, contacts, or files.

Uninstalling the app removes its local data, including the encrypted API key.

This project is unofficial and not affiliated with OpenCode.
